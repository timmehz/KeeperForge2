## 3. Rules for KeeperForge2 and changed versions

If you share KeeperForge2 or a changed version of it:

1. **It must be free.** You may not charge any money to download it, install it, use it or get it.
2. **Its full source code must be public.** Anyone must be able to get it for free, all the time, without signing up or asking first.
3. **It must use this same license.** Include this license file with it. Do not add new rules that take away anything this license allows.
4. **Keep the credits.** Do not remove the copyright line or this license.
5. **Say what you changed.** Make it clear that your version is changed, so nobody thinks it is the original.
6. **Do not use the KeeperForge2 name as your own.** Do not call your changed version "KeeperForge2" or make it look like the official one. You may say it is "based on KeeperForge2".

## 4. Rules for mods

If you make a mod and share it, these rules apply to it. You may give your mod any license you like, as long as that license does not break these rules.

1. **Mods must be free.** Anyone must be able to download, install and use your mod for free. You may not ask for money, or anything else that costs money, to get it.
2. **Mods must have their full source code public at all times.**
   - Anyone must be able to get all of the mod's source code for free, without signing up or asking first.
   - The source code must be for the same version you share. When you share a new version, share its source code at the same time.
   - The source code must be complete. Someone must be able to build the same mod from it.
   - Do not hide or scramble your code (this is called obfuscation) to stop people reading it.
3. **Mods cannot have paid features.**
   - Every part of a mod must be free for everyone, at the same time.
   - This includes new features, changes, bug fixes, crash fixes, test versions (betas), content and anything else in the mod.
4. **Donations are allowed, with rules.**
   - You may ask for and take donations, for example through Patreon, Ko-fi or PayPal.
   - Giving money must **never** give anyone something in the mod that others don't get. That means no early access, no extra features and no exclusive content.
   - Saying thank you to people who donate is fine, for example by putting their names in a credits list.
5. **No locks or tricks.** A mod must not make people do something else to use it or any of its features. For example, it may not make them:
   - make an account or sign up;
   - watch ads;
   - share, like, follow or subscribe;
   - enter a code or key.
6. **Be honest.** A mod must not hide what it does, harm anyone's computer, steal or collect anyone's information, or include viruses or other harmful programs. If a mod connects to the internet, it must clearly say so and why.
7. **Do not pretend to be official.** Do not say or suggest that your mod is made or approved by KeeperForge2, unless it is.
